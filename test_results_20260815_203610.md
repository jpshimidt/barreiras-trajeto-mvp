## Test Procedure

### 1. Code Fix Applied
**Issue Found:** AttributeError when geocoding addresses
- The `Local` dataclass had fields `numero_informado` and `numero_confirmado` added, but older geocoding functions (nominatim, photon, and ORS) were creating Local instances without these fields
- When `_completar_local()` returned early (when no house number), it returned incomplete Local objects missing these new fields
- This caused crashes when trying to display geocoding options in radio buttons

**Fix Applied:**
- Updated `core/nominatim_geo.py` to include `numero_informado=None, numero_confirmado=True` in Local creation
- Updated `core/photon_geo.py` to include `numero_informado=None, numero_confirmado=True` in Local creation  
- Updated `core/endereco_maps.py` to include `numero_informado=None, numero_confirmado=True` in Local creation
- Committed and pushed fix: commit 1d816bc
